Domain & backend

The domain SonuShield protects, and the origin server it forwards clean traffic to. More domains can be added later from the dashboard.

A hostname or IP address, without a scheme or port.
Host and port of your origin server, for example 127.0.0.1:8080.
Leave both empty when using Cloudflare or autoSSL. Certificate and key must both be set, or both be empty.

Secrets

Generated on this page with your browser’s secure random generator. Save them somewhere safe — the dashboard address and the API both need them. They are stored in config.json, which the wizard writes with owner-only permissions.

The internal cookie, JavaScript, and captcha secrets are generated on the server when you save, and never shown here.

Review & save

Check the summary. Saving writes config.json in the directory SonuShield runs from, then stops the wizard. Restart SonuShield afterwards to start the proxy.

A config.json appeared after the wizard started. Saving now will replace it; the existing file is backed up first with a timestamped name.

Configuration saved

The wizard has stopped. Restart SonuShield to start the proxy.
